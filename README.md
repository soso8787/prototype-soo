# 보안길잡이 AI

공공기관 현업 담당자가 AI와 대화하며 방화벽 신청서를 작성하고, ICT인프라·정보보안 담당자가 함께 검토하는 서비스의 프론트엔드입니다.

## 바로 보기

https://team-khfc.github.io/prototype-soo/

## 주요 기능

- **새 신청:** 기획서·구성도·요구사항 정의서(PDF, HWPX, DOCX, XLSX, TXT)를 끌어다 놓으면 문서에서 보안정보를 찾아 근거와 확신 정도와 함께 채우고, 부족한 항목만 대화로 묻습니다. 사업명은 기획서 제목이나 사업 목적으로 자동 생성되며, 업무 설명은 방화벽 규칙과 데이터 흐름도로 바뀝니다. 요청 전 최종 확인 창에서 내용을 검토하고, 작성 중인 신청은 임시 저장·삭제할 수 있습니다.
- **신청 현황:** 단계별 색상 진행 표시, 처리 기한(접수일부터 영업일 기준) 계산과 기한 지남 표시, 상태 필터, 접수 기간·검색, 5건 단위 페이지 나누기를 제공합니다. 담당자 목록은 기한 순으로 정렬됩니다.
- **담당자 협의:** ICT인프라 담당자는 서버 주소와 포트를, 정보보안 담당자는 검토와 보완 요청을 처리합니다.
- **문서함·이력·정책 수명주기:** 검토 초안과 제출본, 처리 이력, 적용된 방화벽 정책의 만료·미사용 관리를 제공합니다.
- **기관 설정:** 인터뷰 질문, 검토 절차, 문서 양식, 점검 기준, 설정 버전을 관리합니다. 기관 양식 파일(HWPX, DOCX, XLSX)을 올리면 칸 이름을 자동으로 채웁니다.

## 파일 구성

| 경로 | 내용 |
| --- | --- |
| `index.html` | 프론트엔드 전체 (HTML·CSS·JS 한 파일, 로고 포함) |
| `docs/design.md` | KRDS 기반 디자인·UI 개발 규칙 v3.0 |
| `docs/logo.png` | 로고 (일반 모드, 투명 배경) |
| `docs/logo-dark.png` | 로고 (다크 모드, 투명 배경) |
| `samples/샘플_주택연금_상담챗봇_사업계획서.docx` | 새 신청 문서 분석 시험용 샘플 기획서 |
| `.nojekyll` | GitHub Pages가 파일을 그대로 배포하도록 하는 설정 |

`index.html`을 브라우저로 열면 별도 빌드 없이 실행됩니다. 문서 분석과 양식 파일 자동 인식은 cdnjs에서 JSZip·SheetJS·pdf.js를 불러오므로 인터넷 연결이 필요합니다. 문서 내용은 서버로 보내지 않고 브라우저 안에서만 읽습니다.
