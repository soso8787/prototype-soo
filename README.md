# 보안길잡이 AI

공공기관 현업 담당자가 AI와 대화하며 방화벽 신청서를 작성하고, ICT인프라·정보보안 담당자가 함께 검토하는 서비스의 프론트엔드입니다.

## 바로 보기

https://team-khfc.github.io/prototype-soo/

## 주요 기능

- **새 신청:** 기획서를 올리거나 대화로 답하면 업무 설명이 방화벽 규칙과 데이터 흐름도로 바뀝니다. 객관식 보기는 누르는 즉시 반영되고, 수집된 보안정보에서 연필 버튼으로 답을 고칠 수 있습니다.
- **신청 현황:** 단계별 색상 진행 표시, 상태 필터, 접수 기간·검색, 5건 단위 페이지 나누기를 제공합니다.
- **담당자 협의:** ICT인프라 담당자는 서버 주소와 포트를, 정보보안 담당자는 검토와 보완 요청을 처리합니다.
- **문서함·이력·정책 수명주기:** 검토 초안과 제출본, 처리 이력, 적용된 방화벽 정책의 만료·미사용 관리를 제공합니다.
- **기관 설정:** 인터뷰 질문, 검토 절차, 문서 양식, 점검 기준, 설정 버전을 관리합니다. 기관 양식 파일(HWPX, DOCX, XLSX)을 올리면 칸 이름을 자동으로 채웁니다.

## 사용자 전환

오른쪽 위 사용자 이름 옆 화살표를 눌러 역할별 화면을 볼 수 있습니다.

- 김민지 (주택연금부, 신청자)
- 박준호 (정보인프라팀, ICT인프라 담당)
- 이서연 (정보보호팀, 정보보안 담당)
- 정해원 (디지털혁신실, 기관 관리자)
